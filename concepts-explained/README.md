## Format for future guides

Each new guide follows the approved Lesson 01 format:

1. **The Big Question** — an accessible question that introduces the topic.
2. **Think of It Like…** — a relatable everyday analogy.
3. **What Makes It Work?** — accurate explanations of the key concepts.
4. **What Did We Actually Build or Test?** — verified observations from the corresponding technical lab.
5. **Why Would Anyone Want This?** — practical applications, benefits, trade-offs, and limitations.
6. **What Did We Learn?** — the meaning of the experiment, not just the procedure.
7. **Three Things to Remember** — memorable takeaways.
8. **Explore the Actual Experiment** — a link to the technical lab documentation and evidence.
9. **AI-Assisted Educational Documentation** — transparent attribution of AI-assisted drafting and human-executed verification.

Keep the existing technical lab READMEs intact. Explain unfamiliar terms in context, avoid overstating results, and never describe incomplete experiments as completed. Future guides should be reviewed against the corresponding technical lab before publication.
